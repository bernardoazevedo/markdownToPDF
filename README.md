Disponível em: <a href="https://md2pdf.space">Markdown Editor</a>

---

**Markdown Editor** é uma ferramenta dedicada à conversão de documentos. A funcionalidade principal é permitir que você edite textos no formato Markdown e visualize o PDF final antes mesmo de gera-lo.

## Funcionalidades

* **Editar textos em Markdown**
* **Personalizar o PDF final**: Altere a cor do texto, do fundo e até mesmo a cor de destaque.
* **Baixar o documento em PDF**

## Tecnologias Utilizadas

* **Linguagens**: PHP e Javascript
* **Parsedown**: Biblioteca utilizada para converter arquivos Markdown para HTML
* **mPDF**:  Biblioteca utilizada para converter HTML em PDF
